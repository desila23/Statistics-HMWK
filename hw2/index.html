01 / THE IDEA

One phrase in.
An address out.

An Ethereum wallet uses different cryptographic tools because it has several different jobs. The words are a backup; the private key authorizes actions; and the public address identifies an account.

A mnemonic phrase is a readable representation of randomly generated secret data. For example, 128 random bits plus 4 checksum bits can be divided into twelve 11-bit groups, each selecting a word from a 2048-word list. With BIP-39, that phrase and an optional passphrase deterministically produce a 512-bit seed. BIP-32 turns the seed into a tree of keys, while BIP-44 gives that tree a familiar structure.

From a selected private key, secp256k1 calculates a public key using the same kind of elliptic-curve multiplication explored in Homework 1. Ethereum then hashes the public-key coordinates with Keccak-256, keeps the final 20 bytes, and applies EIP-55 to make transcription mistakes easier to detect.

Important: these steps are deterministic, but they do not all perform hashing. Key derivation, public-key computation, hashing, checksums, and encoding are different operations with different goals.

03 / DIFFERENT JOBS

Not one algorithm.
Six different roles.

The terms “key generation”, “key derivation”, “public-key cryptography”, “hashing”, “checksum”, and “encoding” describe different operations. Keeping them separate is part of the homework.

OperationPurposeWhere it appears
Key generationCreate fresh, unpredictable secret entropy.Before the mnemonic is produced.
Key derivationDeterministically produce related keys from a seed.BIP-39 / BIP-32 / BIP-44.
Public-key cryptographyCalculate a public key and support digital signatures.secp256k1.
HashingMap data to a fixed-length digest.Keccak-256; SHA-256 in mnemonic checksum.
ChecksumDetect some accidental mistakes, not secure an account.BIP-39 checksum and EIP-55 casing.
EncodingRepresent bytes as words or hexadecimal characters.Mnemonic words and 0x address format.
HASH FAMILY

SHA-512, Keccak-256 and SHA3-256 are not interchangeable.

SHA-512 belongs to SHA-2 and is used inside PBKDF2/HMAC in BIP-39 and BIP-32. Ethereum uses Keccak-256 for addresses. Standard SHA3-256 comes from the Keccak design, but uses a different domain-separation suffix, so the digest is different.

05 / INTERPRETATION

Why the pipeline
needs different tools.

Our main finding is not that one operation is better than another. It is that each has a different responsibility, and statistics must be interpreted in that context.

A mnemonic is useful because humans can back up words more easily than long binary strings. But its security comes from the initial random entropy, not from the appearance of the words. BIP-39 turns the phrase into a repeatable seed, while BIP-32 and BIP-44 let a wallet organize multiple accounts without independently inventing a new secret for every address.

Scalar multiplication on secp256k1 connects a private scalar to a public point, the relationship used in elliptic-curve signatures. Keccak-256 then converts public-key bytes into a fixed-length digest, from which Ethereum takes the last 20 bytes to form an address. EIP-55 only changes the address's letter casing so some transcription mistakes can be detected; it does not add entropy or make the private key harder to guess.

Our statistical experiments describe the behavior we observe. Close-to-balanced bits and digit frequencies are consistent with the outputs looking dispersed, while a one-bit change typically alters many Keccak output bits. However, a small sample does not prove security, and different algorithms do not need to share the same statistical properties. In particular, key derivation and checksums should not be judged as if they were hash functions.

Taken together, the two homeworks tell one story: Homework 1 examined the mathematical step from private to public key, while this homework shows where that private key comes from and how the public key becomes a usable Ethereum address. A practical wallet relies on multiple well-defined primitives because no single algorithm can correctly perform all these tasks.
