# Statistics — Cryptography Homeworks

Interactive projects developed for the **Statistics course** of the Master's Degree in Cybersecurity at Sapienza University of Rome (2026/2027).

The projects explore cryptographic algorithms through practical simulations, statistical analysis, and interactive visualizations.

## Homeworks

### 01 — From Private Key to Public Key
Explores elliptic-curve scalar multiplication using a toy curve, with step-by-step visualization and statistical analysis of the resulting public keys.

**[Open Homework 1](https://desila23.github.io/Statistics-HMWK/hw1/)**

### 02 — From Wallet Seed to Ethereum Address
Demonstrates the Ethereum wallet derivation pipeline, from BIP-39 mnemonic phrases to EIP-55 checksummed addresses, including cryptographic primitives and statistical experiments.

**[Open Homework 2](https://desila23.github.io/Statistics-HMWK/hw2/)**
