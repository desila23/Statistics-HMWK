Welford’s Algorithm & Sampling

Online Statistics, Unbiased Estimation and Sampling Experiments

Update a mean and variance one observation at a time. Then simulate repeated samples to see how those estimates vary.

Derive the update ↓
The experiment

One score per system.

Each of m hackers attempts n systems. The resulting integer score measures an abstract outcome from 0 to 10. This is a statistical model, not a realistic model of cyberattacks.

The mean measures level; the variance measures spread. The distribution has fixed parameters, while estimates change with the observed sample. An online algorithm updates a running state as observations arrive, without retaining every score.

Learning objectives

  • Derive and implement the mean and sum of squares updates.
  • Compare sample estimates with known parameters.
  • Separate the effects of sample size and simulation size.
Exercise 1

From the definition to three lines

1. Knuth’s mean recurrence

Start with the average of the first n observations. Split off the newest observation. The sum of the earlier values is their mean multiplied by their count.

mₙ = (Σᵢ₌₁ⁿ xᵢ)/n
= [(n−1)mₙ₋₁ + xₙ]/n
= mₙ₋₁ + (xₙ − mₙ₋₁)/n

The last line follows by writing (n−1)mₙ₋₁ as nmₙ₋₁ − mₙ₋₁. Set δ = xₙ − mₙ₋₁ and h = δ/n. The updated mean is mₙ₋₁ + h.

2. Welford’s sum of squares recurrence

SSₙ = Σᵢ₌₁ⁿ (xᵢ − mₙ)²

Let dᵢ = xᵢ − mₙ₋₁ for i < n. Under the new mean, each old deviation becomes dᵢ − h. Expanding its square and summing gives:

Σᵢ₌₁ⁿ⁻¹ (dᵢ − h)²
= SSₙ₋₁ − 2h Σᵢ₌₁ⁿ⁻¹ dᵢ + (n−1)h²
= SSₙ₋₁ + (n−1)h².

The cross term vanishes because the deviations from the old mean sum to zero. The newest deviation is δ − h. Add its square and substitute h = δ/n:

SSₙ = SSₙ₋₁ + (n−1)h² + (δ−h)²
= SSₙ₋₁ + δ² − 2δh + nh²
= SSₙ₋₁ + ((n−1)/n)δ²
= SSₙ₋₁ + δ(xₙ − mₙ).

These recurrences apply for n ≥ 2; the first observation sets m₁ = x₁ and SS₁ = 0.

3. The sample variance

SSₙ/n is the population variance of the observed values treated as the whole population. For an i.i.d. sample estimating a parent population’s variance, use s²ₙ = SSₙ/(n−1), n ≥ 2. It is undefined at n = 1.

s²ₙ = [SSₙ₋₁ + ((n−1)/n)δ²]/(n−1)
=n−2n−1sn−12+δ2n , n ≥ 3.

For n = 2, obtain the variance directly from SS₂; s²₁ does not exist.

The three-line update

Start with count = 0, mean = 0 and M2 = 0. Increment count before these lines. The new mean uses the old deviation, and M2 stores the updated SS.

const delta = x - mean;
mean += delta / count;
M2 += delta * (x - mean);
Complete JavaScript function
function onlineStats(values) {
  let count = 0, mean = 0, M2 = 0;
  for (const x of values) {
    count++;
    const delta = x - mean;
    mean += delta / count;
    M2 += delta * (x - mean);
  }
  return {
    count, mean: count ? mean : null, M2,
    sampleVariance: count > 1 ? M2 / (count - 1) : null
  };
}

Welford uses constant state and avoids the subtraction of nearly equal large quantities in the naive sum-of-squares shortcut. It is not more accurate than exact arithmetic.

Exercise 2 · Probability model

Eleven scores, equal probability

For each attempt, draw independently from the discrete uniform distribution on {0, 1, …, 10}. Each score has probability 1/11. This fixed distribution is easy to simulate and has exact reference values.

μ = (0 + 1 + ··· + 10)/11 = 55/11 = 5
E[X²] = (0² + 1² + ··· + 10²)/11 = 385/11 = 35
σ² = 35 − 5² = 10;   σ = √10

Interpretation

Why does this matter for inferential statistics?

Bias is the difference between an estimator’s expectation and its target. E[mean] = μ by linearity. Also, SS = Σ(Xᵢ−μ)² − n(mean−μ)². Under i.i.d. sampling with finite variance, its expectation is nσ² − σ² = (n−1)σ². Thus E[s²] = σ² with the n−1 divisor; dividing by n instead gives (n−1)σ²/n in expectation.

Sampling variability is how estimates change across repeated samples. Estimator variance measures that spread. Neither a single sample’s s² nor the average of the s² values measures the spread of sample means. The lab estimates the spread across hackers with the m−1 divisor.

Consistency means convergence in probability as n grows. The law of large numbers applies to both the sample average of X and the sample average of X² for our bounded scores. Since s² = n/(n−1) × (average of X² − mean²), it also converges in probability to σ².

Estimation accuracy concerns closeness to the target. Mean squared error combines squared bias and estimator variance. Larger n generally gives more informative estimates here, without guaranteeing that a particular sample is closer.

Monte Carlo error comes from using only m simulated samples to estimate sampling properties. For example, the standard error of the average sample mean is √(10/(nm)); for the average sample variance it is √(Var(s²)/m). Increasing m reduces this error and does not change an individual hacker’s estimator distribution at fixed n.

When population parameters are unknown, these distinctions help choose estimators, quantify uncertainty and decide how much data to collect.

Takeaways

Conclusions

Welford updates mean and SS without keeping the observations. The sample mean and the sample variance with denominator n−1 are unbiased for μ = 5 and σ² = 10. Compare the simulated average of each estimator with its own target.

Theory predicts smaller variability for both estimators as n increases. The charts measure that behavior using finite simulations: random departures from theory, including local reversals, are possible. Increasing m improves Monte Carlo precision. This helps explain why an estimate can be unbiased and still uncertain, and why collecting more observations can improve inference.
