## Scope and remaining limits

No known blocking issue remains in the tested Chromium environment. Responsive frames test CSS layout, not real-device touch behaviour. Safari/iOS, Firefox, screen-reader output and every browser/device combination were not tested. MathML and module workers require a modern browser; use HTTP(S), not a local file URL.

Maximum-budget termination was tested, but a full 100-million-increment completion benchmark was not required. Runtime depends on device; four default workers can compete on a low-power phone. Chart rendering and exact finite-law calculations happen on the main thread after workers finish. Only the first eight full paths are retained. Other attacker paths retain checkpoint/final totals, avoiding an n×m matrix.

All statistical conclusions are conditional on the i.i.d. model. Deterministic pseudorandom simulation cannot demonstrate real-world cyber-risk or prove probabilistic theorems.
